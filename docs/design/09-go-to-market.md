# 09. マーケティング・差別化・事業設計

前提：[08](08-operations.md) のコストモデル（変動費 50〜100円/試合）が価格設計の下限制約。
競合・市場の定量データは調査結果で随時更新する（§競合比較 の出典参照）。

## ターゲットセグメント（優先順）

| 優先 | セグメント | 特徴 | 獲得経路 |
|---|---|---|---|
| 1 | 社会人サークル・草トー層（20-40代） | 自腹・意思決定が個人・LINEグループが既にある・上達意欲と可処分所得の交点 | 共有リンク経由の口コミ（下記バイラルループ） |
| 2 | テニススクール生（一般・ジュニア） | 継続率が高い・コーチが介在 | スクール・コーチ提携（B2B2C） |
| 3 | 部活（中高） | ボリュームは大きいが決済者が別（保護者・学校）・未成年同意が必要 | チーム一括導入（Phase 2以降） |
| 4 | コーチ・テニス系発信者 | 少数だが増幅器。編集自動化の直接的な受益者 | YouTube限定公開連携（[05](05-tech-stack.md)）・直接アプローチ |

- **最初の1年はセグメント1に集中**。意思決定が個人で完結し、フィードバックループが最速。
  セグメント4は人数でなく**発信力**を買う（初期の認知獲得）。

## 差別化（vs 競合）

### 競合比較

| 観点 | SwingVision | 本アプリ |
|---|---|---|
| プラットフォーム | iOS / Apple Watch 中心 | **PWA（iOS/Android/PC）** — 日本のAndroidシェアを取りこぼさない |
| スコア・判定 | 自動判定（精度への不満が既知） | **半自動 + 信頼度明示 + unknown許容** — 「誤った断定より未分類」 |
| コート環境 | ハードコート中心の設計 | **オムニコート対応を明示的に優先**（日本の圧倒的多数派、[03](03-recording-guidelines.md)） |
| フィードバック | スタッツ表示が主 | **原因分析 + 継続アドバイス配信**（LINE週次、[07](07-advice-delivery.md)） |
| 言語・文化 | 英語圏中心 | 日本語ネイティブ・LINE・草トー/サークル文化前提 |
| 価格 | サブスク（ドル建て） | 円建て・後述のフリーミアム |

- 差別化の核は機能表ではなく**2つの構造**：
  1. **誠実さの設計** — 信頼度を隠さない。競合の「自動だが間違う」への直接の回答であり、
     信頼はコーチング製品のリテンションの核。
  2. **継続の設計** — 解析して終わりではなく「振り返る→改善する→また練習する」の
     ループを配信で駆動する（[07](07-advice-delivery.md)）。ここに直接競合がいない。

### 模倣への防御（moat）

| 資産 | 蓄積構造 |
|---|---|
| 日本環境の正解データ | オムニコート・スマホ撮影・ユーザー修正ラベルの蓄積（[08](08-operations.md) の学習ループ）。海外勢が最も真似しにくい |
| アドバイス効果データ | AdviceLog：どのアドバイスがどのユーザー層に効いたか（[07](07-advice-delivery.md)）。時間でしか買えない |
| YAMLルール資産 | コーチ知見のルール化はコードでなく**ドメイン知識の蓄積**。taxonomyバージョンが増えるほど厚くなる |

## 価格設計（フリーミアム）

| プラン | 価格 | 内容 |
|---|---|---|
| Free | 0円 | 月2試合まで解析・編集。原本保持30日。共有リンク無制限（**バイラル面は制限しない**） |
| Pro | 月980円（想定） | 解析無制限*・週次ダイジェスト・アドバイス配信・傾向分析・原本1年保持 |
| Team（Phase 2以降） | 月4,980円〜 | スクール・部活向け。複数メンバー・コーチ閲覧・チーム集計 |

- 変動費50〜100円/試合に対し、Pro層の想定利用（月4〜8試合）で粗利が成立する構造。
  *「無制限」はフェアユース上限（月20試合程度）を規約に置く。
- **Freeの制限は「本数」であって「共有」ではない**。共有リンクが獲得チャネルなので、
  無料ユーザーの共有体験は削らない。
- アドバイス配信（差別化の核）をPro専用にすることで、無料→有料の転換動機を
  「もっと解析したい」と「上達支援を受けたい」の2本にする。

## 獲得：バイラルループが主、広告は従

```
ユーザーがアップロード → 編集済み動画の共有リンクをサークルLINEに投稿
    → 対戦相手・仲間が視聴（自分が映っている動画は視聴動機が最強）
    → 視聴ページに「自分の試合も解析する」導線 + 実物の解析結果デモ
    → 新規登録 → 最初のアップロード → ループ
```

- **共有リンクの視聴ページがランディングページを兼ねる**。製品説明より
  「実際の解析結果 + 自分が映っている動画」が最強のデモ。
- 計測：K係数（共有リンク経由の新規登録 ÷ アクティブユーザー）を主要KPIに。
  Phase 0 の成功指標「アップロードの50%以上で共有」（[01](01-mvp-scope.md)）はこのループの前提。
- 補助チャネル：
  - テニス系YouTuber・コーチへの無償提供（セグメント4 = 増幅器）
  - 草トー大会主催者との提携（大会動画の解析特典）
  - SEO：「テニス 動画 編集」「テニス 試合 振り返り」等の実用クエリ（記事は薄く、デモを厚く）
- **有料広告はK係数とリテンションが立つまで打たない**。

## オンボーディング（導入体験）

初回体験の敵は「撮影ガイド読了 → 次の試合まで待つ」の断絶。以下で埋める：

1. 登録はLINEログインのみ（友だち追加と同時、[07](07-advice-delivery.md)）
2. 登録直後に**過去のスマホ動画をそのまま1本アップロードさせる**
   （画角が悪くてもプリフライトが判定し「次はこう撮るともっと分かる」と返す —
   撮影ガイドを**説教でなく結果として**体験させる）
3. 初回解析完了のLINE通知 → 編集済み動画 → 共有ボタンまでを1画面で
4. 撮影ガイド（[03](03-recording-guidelines.md)）は「次の試合の前」にLINEでリマインド

## KPI（フェーズ別の焦点）

| フェーズ | 主要KPI | 目標の考え方 |
|---|---|---|
| Phase 0 | 共有率（>50%）、初回アップロード完遂率、解析所要時間 | ループの部品が動くか |
| Phase 1 | K係数、週次リテンション、ユーザー修正率（<10%） | ループが回るか・精度が信頼に足るか |
| Phase 2 | Free→Pro転換率（目安3〜5%）、アドバイス既読率・「役に立った」率、解約率 | 差別化が金になるか |
| 共通 | 1試合あたり変動費（実測）、LTV/CAC | ユニットエコノミクス |

## リスクと留意

| リスク | 対応 |
|---|---|
| SwingVision等の日本語化・Android対応 | 先行の12〜24ヶ月で日本環境データとアドバイス効果データを蓄積（moat参照）。機能追随でなくデータで防御 |
| 大会・施設の撮影規程 | 撮影ガイドに「主催者・相手の許可」を明記。共有リンクの既定を限定公開に |
| 映り込みプライバシー | 相手スタッツの非表示既定（[07](07-advice-delivery.md)）。通報導線を視聴ページに設置 |
| 「解析が外れる」評判リスク | unknown設計 + 信頼度表示が回答。マーケ文言でも精度を誇張しない（「全自動」と言わない） |
| 単発利用で離脱（試合頻度が低い層） | 練習動画・壁打ちも対象にする軽量モード（Phase 1で検討）。週次ダイジェストは試合が無い週も「前回の復習」を配信 |
