# 06. プロ比較用参照データの調達戦略（ユースケース②）

## 論点

サーブメカニズム比較に使う「プロのフォームデータ」をどう調達・作成するか。
著作権・ライセンス・肖像権のリスクを含めて決める。

## 結論：放送映像からの抽出は採用しない。2本立てで参照データを作る

### ❌ 採用しない案：放送・YouTube映像から骨格抽出

- 放送映像は著作物であり、解析目的でも商用サービスへの組み込みは権利処理が必要。
- 骨格座標データ自体の著作物性は低いという議論はあるが、**選手の肖像・パブリシティ権**の
  問題が残る（「フェデラーのフォームと比較」と銘打てば選手名の商用利用になる）。
- 権利リスクを負ってまで得る価値がない：ユーザーに必要なのは「特定プロとの一致度」ではなく
  「良いフォームのレンジに入っているか」。

### ✅ 案1（主軸）：バイオメカニクス文献の指標レンジをパラメータ化

テニスサーブのバイオメカニクス研究（ITF Coaching & Sport Science Review、
スポーツ科学系ジャーナル）には、エリート選手のフェーズごとの関節角度・タイミングの
統計レンジが公開されている。これを**「参照レンジ」としてYAML化**する。

```yaml
# reference/serve-mechanics.v1.yaml（Phase 3で整備）
phases: [preparation, toss, trophy, acceleration, impact, follow_through]
metrics:
  - id: knee_flexion_at_trophy
    phase: trophy
    unit: deg
    elite_range: [95, 120]      # 文献ベースの推奨レンジ
    tolerance: 8
    advice_key: knee_bend       # アドバイス文テンプレートへの参照
  - id: elbow_height_at_trophy
    phase: trophy
    unit: relative_shoulder     # 肩基準の正規化値（カメラ距離に不変）
    elite_range: [0.9, 1.15]
  - id: toss_apex_to_impact_ms
    phase: impact
    unit: ms
    elite_range: [350, 550]
```

利点：

- 権利リスクゼロ。出典を明記でき、コーチング上の説明可能性が高い。
- 「あなたのトロフィーポーズの膝屈曲は128°で、推奨レンジ95–120°より浅い」という
  **定量フィードバック**が直接出せる（特定選手比較より実用的）。
- miss taxonomyと同じ「基準の外出し」設計思想（YAMLで調整可能）。

注意：文献値はエリート成人男子基準が多い。レベル・性別・年齢での補正係数を持てるよう
`elite_range` をプロファイル別に差し替え可能な構造にする。

### ✅ 案2（補助）：契約コーチ・上級者の撮り下ろし参照映像

- 提携コーチ（または競技経験者）と**権利許諾契約を結んだうえで**、推奨撮影条件
  （[03](03-recording-guidelines.md)）と同一アングルで模範サーブを撮り下ろす。
- 用途：
  1. UI上の「お手本動画」としての並列表示（骨格オーバーレイ付き）
  2. 同一アングル・同一パイプラインで抽出した骨格系列＝**比較アルゴリズムの正解データ**
  3. フェーズ分割モデルの学習データ
- 選手比較の「見た目のわかりやすさ」はこちらで担保し、定量評価は案1で行う分業。

### 検討済み・保留：公開研究用データセット

- スポーツ動作の公開データセット（モーションキャプチャ系）は存在するが、テニスサーブに
  特化し商用利用可能なものは限られる。見つかれば案1のレンジ検証に使う（製品への直接組み込みはしない）。

## 比較アルゴリズムの設計方針（Phase 3）

1. MediaPipe Poseで骨格系列を抽出（60fps、斜め後方アングル）
2. サーブをフェーズ分割（トス開始・トロフィー・インパクトのキーイベント検出）
3. フェーズごとに `serve-mechanics.v1.yaml` の指標を算出
   - カメラ距離・体格に不変な**正規化指標**（角度、体節長比、タイミング比）のみ使う
4. レンジ逸脱を重要度順にランキング → 上位2〜3件だけをフィードバック
   （全部指摘しない。行動変容につながる数に絞る）
5. ランドマークのvisibilityが低いフレームが多い場合はその指標を出さず、再撮影ガイドを提示

## リスクまとめ

| リスク | 対応 |
|---|---|
| 放送映像の著作権 | 使用しない |
| 選手の肖像・パブリシティ権 | 特定選手名を使った比較機能を作らない |
| 文献値の適用範囲（レベル差） | プロファイル別レンジ＋「参考値」表記 |
| 撮り下ろし映像の権利 | 契約で利用範囲（アプリ内表示・学習利用）を明記 |
| 誤った指導リスク | 断定を避けるトーン、レンジ根拠の出典表示、医学的助言はしない旨の明記 |
