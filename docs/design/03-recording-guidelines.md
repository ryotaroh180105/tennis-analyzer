# 03. 撮影要件（カメラ設置ガイドライン）

## 方針：強制ではなく「推奨＋自動判定＋フィードバック」

SwingVisionはフェンスマウントをほぼ前提化しているが、サークル・カジュアル層は
三脚すら持っていないことが多い。**撮影条件を強制するとファネルの入口で離脱する**ため、

1. 推奨条件をアプリ内でガイド（初回撮影チュートリアル＋イラスト）
2. アップロード時に**プリフライトチェック**で自動判定
3. 条件を満たさない場合も**できる範囲の解析を実行**し、「次回こう撮るともっと分析できます」と返す

という3段構えにする。

## 推奨撮影条件（試合分析・ユースケース①）

| 項目 | 推奨 | 最低ライン | 理由 |
|---|---|---|---|
| 位置 | ベースライン後方センター延長線上 | 後方コーナー | コート全面とボール軌道の奥行きを確保 |
| 高さ | 2m以上（フェンスマウント/三脚） | 1.5m | 高さがないと奥コートの選手・バウンド位置が潰れる |
| 画角 | コート全面＋両選手が常時フレーム内 | 自コート全面 | ホモグラフィ推定と選手追跡の前提 |
| 向き | 横向き（ランドスケープ） | 同左 | 縦動画はコートが収まらない |
| 解像度/fps | 1080p / 30fps | 720p / 24fps | ボール追跡はfpsに敏感。※60fpsはサーブ専用モード（短尺クリップ）のみの推奨。試合丸撮りの60fpsはファイルサイズが倍増しアップロード上限（[10](10-phase0-implementation-plan.md)）を超えるため推奨しない |
| その他 | 固定（手持ち不可）、逆光回避 | 固定 | 追跡・コート検出の安定性 |

## 推奨撮影条件（サーブ解析・ユースケース②、Phase 3）

姿勢推定の技術的制約（遠距離で精度低下、横向き高速動作で追跡劣化、前面/背面の反転誤認識）を
踏まえ、試合撮影とは**別の専用モード**にする。

| 項目 | 推奨 |
|---|---|
| 位置 | 打者の**斜め後方45°**、距離3〜5m |
| 高さ | 腰〜胸の高さ（1.0〜1.5m） |
| 画角 | 足元からトス最高点まで全身＋頭上1m |
| fps | 60fps以上（インパクト前後の高速動作のため） |
| 補助 | 1本ずつ撮影（連続撮影より区切りが明確でフェーズ分割が安定） |

- 真横（ネット側）からの撮影は回内動作が見えやすいが、コート外に出られない環境が多いため
  斜め後方を第一推奨とする。将来「2アングル撮影（斜め後方＋真横）」をオプション化。

## プリフライトチェック（precheck：アップロード直後・**CPUで・GPU起動前に**実行）

先頭60秒を2fpsでサンプリングして以下を判定し、**高価なGPU工程（ingest正規化・解析）の前に**
ユーザーへ結果を返す（60秒未満の動画は全長。白線検出＋ホモグラフィは120フレーム程度なら
CPUで足りる）。判定結果は `matches.preflight_report` に保存する（[10](10-phase0-implementation-plan.md)）。
実装注意：スマホ録画のmp4はmoovアトムが末尾にあることが多く、原本の「先頭だけ読む」には
末尾Rangeでのmoov取得が必要。メタデータ検査（解像度/fps/HDR/VFR/回転）は同じprecheckジョブの
ffprobeで行い、入力不正はここで弾く（GPU費用を使わない）。

| チェック | 判定方法 | NG時の挙動 |
|---|---|---|
| コート検出 | 白線検出＋ホモグラフィの残差 | **縮退モードで続行**：コート座標系なしで、活動量ベースの区間分割＋編集のみ実行（スタッツ・分類は不可）。「次回こう撮ると分析もできます」とガイド提示。※冒頭方針「できる範囲の解析を実行」の具体化。オムニコートの白線コントラスト低下でここに落ちやすいため、中断にはしない |
| 画角カバレッジ | **遠側2隅＋サイドラインの消失点**が画面内か（推奨位置では手前2隅は画面下端外が正常のため、4隅判定にしない） | 部分解析モード（映っている範囲のみ）で続行＋警告 |
| カメラ固定 | フレーム間のグローバルモーション | ブレ補正を試行、大きい場合は警告 |
| 明るさ/逆光 | 輝度ヒストグラム | 警告のみ |
| 解像度/fps | メタデータ | 720p/24fps未満は警告＋精度低下の明示 |

判定結果は `preflight_report` として match レコードに保存し、
解析結果の信頼度表示（「この試合の解析精度：★★☆」）の根拠にする。

## 環境要因への対応

- **オムニコート**（日本で最多、SwingVisionの弱点）：砂入り人工芝は白線コントラストが低い。
  コート検出モデルの学習データにオムニコートを重点的に含める。バウンド位置の推定信頼度は
  ハード/オムニでしきい値を変える。
- **ナイター/屋内**：フリッカー（照明周波数とシャッタ速度の干渉）検出時は警告。
- **風雨**：対応しない（信頼度低下として現れるに任せる）。
